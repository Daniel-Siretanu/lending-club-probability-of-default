# lending-club-probability-of-default
Probability of Default (PD) model on Lending Club loans (2007–2015): WoE logistic regression scorecard, monotonic LightGBM challenger, Explainable Boosting Machine, SHAP reason codes, and out-of-time validation (AUC, Gini, KS, PSI) aligned with SR 11-7 / SS1/23.
